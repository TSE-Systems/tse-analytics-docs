# TSE Analytics user manual

This repository publishes the TSE Analytics user manual at
<https://tse-systems.github.io/tse-analytics-docs/>.

The manual is written and built in the TSE Analytics repository (`docs/user/`). Its `task docs:publish` pushes each
build to the `gh-pages` branch here, which GitHub Pages serves as it is - do not edit `gh-pages` by hand, the next
publish replaces it.

The manual of the earlier Qt-based desktop application is kept on the `v1` branch and the `qt-manual` tag.
