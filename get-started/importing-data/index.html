Importing data

A dataset enters the workspace through File ▸ Import Dataset… or the Import button above the workspace tree. TSE Analytics reads three kinds of files: the .tse export of the PhenoMaster software, the IntelliCage export (.zip) and the IntelliMaze export (.zip).

Exporting from PhenoMaster

Section titled “Exporting from PhenoMaster”

TSE Analytics reads the export the PhenoMaster software writes for it, not the raw recordings:

  1. In PhenoMaster, open the Export menu and choose TSE Analytics.
  2. Select the data to export. Besides the main data you can add the ActiMot raw data (Act.raw), the calorimetry bins (Calo.bin) and the DrinkFeed bins (DFT.bin); with a licensed BodyWeight module the DrinkFeed file also holds the body weights.
  3. Click Start Export, keep or change the proposed name — Export, the project id, the date and the time, with the extension .tse — and click Save. A message confirms the finished export.

Importing a PhenoMaster export

Section titled “Importing a PhenoMaster export”

  1. Choose File ▸ Import Dataset… and select the .tse file.

  2. Choose the optional tables to import. Only the tables the file contains can be ticked.

    • Calo bin data — the calorimetry bins, for the Calo viewer.
    • DrinkFeed bin data and DrinkFeed raw data — for the DrinkFeed viewer.
    • ActiMot raw data — for the ActiMot viewer.
    • Group Housing data — for the Group Housing viewer.

  3. Click Import. The import runs in the background; a message shows its progress, and the dataset appears in the tree when it is done.

Tip

Large exports take longer to import and use more memory. Tick only the tables you need; you can import an export again with other tables later.

During the import the dataset’s metadata is extracted: the animals with their properties (box, weight, …), the variables with their units and default aggregation, the sample interval and the recording period. Look at them in the Info, Animals and Factors tabs of the sidebar.

Importing an IntelliCage or IntelliMaze export

Section titled “Importing an IntelliCage or IntelliMaze export”

Choose File ▸ Import Dataset… and select the .zip file. There are no options; the import creates the dataset with the tables the export holds — for IntelliCage the Visits and Nosepokes tables, for IntelliMaze one raw table per module. See IntelliCage and IntelliMaze.

Several datasets in one workspace

Section titled “Several datasets in one workspace”

Import as many datasets as you like, one after the other; each keeps its own animals, factors, variables and settings. The menus and the toolbox act on the dataset (or datatable) that is selected in the tree. Datasets of the same design can be merged into one; see Merging datasets.

Note

CSV files and the import of extension data from CSV are internal features (Settings ▸ General ▸ Enable internal features). With them on, the file picker also accepts .csv and the dataset’s context menu offers Import calo data…, Import drink/feed data…, Import ActiMot data… and Import group housing data….
