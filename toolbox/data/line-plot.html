Line Plot

The Line Plot draws several variables over time as group means with an error band, with the dark phases shaded. It is the plot for a report; for browsing a long recording use the Fast Line Plot.

Settings

  • Variables — tick the variables to draw; each gets its own panel.
  • Group by — Animal (one line per animal) or a factor (one line per level, the mean of its animals).
  • Error bar — the band around a group mean: None, Confidence Interval, Percentile Interval, Standard Error (the default) or Standard Deviation. No band is drawn for a group with one animal.
  • Line width — in points.

Result

One panel per variable, time on the x-axis, one line per group with its band, and the dark phases of the light cycle shaded. At one-minute intervals over several days the plot is dense; resample the datatable to an hourly interval for a clearer picture (Deriving a datatable).
