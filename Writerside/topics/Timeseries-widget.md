# Time Series

The _Timeseries_ widget in TSE Analytics provides several options to perform time series analysis and thereby to analyze data collected over time during PhenoMaster experiments. 

![Figure: Time Series widget](image_63.png)

*Figure: Time Series widget*

>**Note:** 
<br/> Time series analysis in TSE Analytics can only be performed using data of a single animal. The respective animal of interest can be chosen from the **Animal** dropdown menu in control panel of the _Timeseries_ widget.
<br/> 
<br/> Animal selection in the Animal widget is not considered for time series analysis.
{style='note'}
